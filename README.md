# Island Braids & Beauty

Premium, responsive static website for Island Braids & Beauty, hosted with GitHub Pages.

## Website

GitHub Pages URL (once Pages is enabled): https://glenroygriffiths876-collab.github.io/ISLAND-BRAIND-AND-BEAUTY/

## Deployment

In GitHub, open **Settings → Pages**, select **Deploy from a branch**, choose **main** and **/(root)**, then save. The website serves directly from `index.html`. You may need to wait for GitHub Pages deployment before the URL loads.

## Updating

- Main website text, layout, colours, navigation, and responsive styling: `index.html`.
- Booking URL: search `https://islandbraidsbeauty.as.me/` in `index.html`.
- Shop URL: search `https://islandhairnwigs.com/`.
- Social URLs: search Instagram, TikTok, Facebook in `index.html`.
- Policies: search `id="policies"` in `index.html`.
- Photos: replace external illustrative image URLs with authentic optimized business photography. **Current hero, About, service and shop photos are illustrative, not verified business photos.**
- Website icon currently refers to the original logo hosted on islandbraids.us. Move it into the repository for reliable long-term use when an authorized local file is available.

## Important functional limitations

GitHub Pages is static hosting. Actual reservations and payments happen on the external Acuity booking site and external store. The site contains no fake checkout, login or fabricated booking availability. The HTML may need content approval for policies/prices, exact locations, and real portfolio photography prior to public promotion.

## Mobile

Layouts support narrow phones, tablets and desktops. Navigation toggle and policy accordions use built-in accessible controls and minimal JavaScript.
